# Contributing

1. Fork the repository and create a branch from `main`.
2. Run `npm install`, then `npm run dev`.
3. Before opening a PR: `npm run typecheck && npm run lint && npm run build`.
4. Code style: TypeScript, no code comments, shadcn/ui components. New tools are registered in `src/components/tools/tools-view.tsx`.
5. Describe what changed and how to verify it in the PR; attach a screenshot for UI changes.

Ideas and bugs go to Issues.
